# Board glossary

The words the board context uses for drawing the game. `zone`, `phase`, and
`stack` are in the book glossary; these are the layout terms this context adds.

## Fixed slot

A set position on the board where a kind of card or zone always sits — Arena-style,
never dragged. The layout is positional, so the same `zone` is always in the same
place (project scope).

- **Status:** validated

## Phase rail

The strip that shows the current `phase` and, in `play mode`, advances on space.
In `watch mode` it is display-only.

- **Status:** validated
